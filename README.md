# 嬷嬷模拟器 momomoniqi

> 把你最严肃的角色，宠成全网嬷嬷。

纯前端的整活式互动玩具：上传任意角色图（宫斗嬷嬷、老板头像、自家猫），10 秒像素化成"电子嬷嬷"，摸摸头、rua 一下、拍拍、喂食，收获无厘头反差文案与离谱的嬷力值，最后一键生成竖版「嬷嬷认证卡」PNG 发到社媒。

产品规划详见 [docs/PRODUCT_PLAN.md](docs/PRODUCT_PLAN.md)。

## 本地运行

要求 Node.js ≥ 20。

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5173）
npm run build    # 类型检查 + 生产构建，产物在 dist/
npm run preview  # 预览生产构建
```

纯静态产物，`dist/` 可直接部署到 GitHub Pages / 任意 CDN。

## 功能概览

- **上传角色**：拖拽或点击选图，全程浏览器本地处理，图片不出浏览器；最近 3 个角色存 localStorage 可一键复用；未上传时使用内置像素嬷嬷。
- **像素化 / 风格化**：颗粒度 16–96 格可调；四种风格预设 —— 像素原味、复古掌机（四色绿屏）、赛博粉（霓虹色阶）、墨水印（黑白盖章），基于亮度色阶映射 + Bayer 抖动实现。
- **互动开嬷**：摸摸头 / rua 一下 / 拍拍 / 喂食，每个动作有专属角色形变动画、道具入场动画与粒子飘散。
- **搞笑反馈**：每次互动随机弹出无厘头文案；嬷力值 +3~15，12% 概率触发暴击 +66；跨过 50 / 150 / 300 / 600 / 1000 解锁「见习小嬷嬷」到「宇宙第一嬷」五档成就。
- **分享传播**：Canvas 生成 900×1200 认证卡（像素角色 + 嬷力值 + 段位 + 语录）下载 PNG，或一键复制带话题标签的传播文案。

## 技术栈

Vite + React 19 + TypeScript，原生 Canvas 2D 做像素化与分享卡渲染，手写 CSS 完成全部动效。零第三方运行时依赖（仅 react / react-dom）。

## 合规提示

所有图片处理均在你的浏览器内完成，不上传、不存储。请只上传你有权使用的图片。
