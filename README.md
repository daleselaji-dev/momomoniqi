# 嬷嬷模拟器 momomoniqi

> 把你最严肃的角色，宠成全网嬷嬷。

纯前端的整活式互动玩具 + DIY 同人二创社区：上传任意角色图（宫斗嬷嬷、老板头像、自家猫），10 秒像素化成"电子嬷嬷"，用摸头 / rua / 哄睡 / 丢球等 7 个动作过度宠溺它（拓麻歌子式养育：精力 + 亲密度），收获无厘头反差文案、8-bit 音效与离谱嬷力值；既可以一键生成竖版「嬷嬷认证卡」PNG 发社媒，也可以**过审后发布到社区展台**，被其他玩家点赞、点彩。

产品规划详见 [docs/PRODUCT_PLAN.md](docs/PRODUCT_PLAN.md)。

## 本地运行

要求 Node.js ≥ 20。

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5173）
npm run build    # 类型检查 + 生产构建，产物在 dist/
npm run preview  # 预览生产构建
```

纯静态产物，`dist/` 可直接部署到 GitHub Pages / 任意 CDN。

## 功能概览

- **上传角色**：拖拽或点击选图，全程浏览器本地处理，图片不出浏览器；最近 3 个角色存 localStorage 可一键复用；未上传时使用内置像素嬷嬷。
- **像素化 / 风格化**：颗粒度 16–96 格可调；**7 种风格预设** —— 像素原味、复古掌机（四色绿屏）、赛博粉（霓虹色阶）、墨水印（黑白盖章）、拓麻液晶（三阶灰绿电子宠物屏）、贴纸手账（粉彩糖果）、黑白漫画（1-bit 网点），基于亮度色阶映射 + Bayer 抖动实现。
- **互动开嬷**：摸摸头 / rua 一下 / 拍拍 / 喂食 / **哄睡 / 夸夸 / 丢球**，每个动作有专属角色形变动画、道具入场动画、粒子彩屑与 Web Audio 现场合成的 8-bit 音效（顶部导航一键静音，偏好持久化）。
- **养育状态**：精力 / 亲密度两条像素数值条，喂食哄睡回精力、玩耍涨亲密耗精力，实时派生心情文案——拓麻歌子式轻养成。
- **搞笑反馈**：每次互动随机弹出无厘头文案；嬷力值 +3~15，12% 概率触发暴击 +66（震屏 + 白闪 + 号角音效）；五档成就 toast。
- **社区展台（本地模拟）**：DIY 作品发布到社区 feed（localStorage 持久化），支持点赞（可切换）与点彩（累加 + 彩色粒子爆发）；内置 5 条种子同人作品，支持「全部 / 我的」过滤；移动端单列 feed + 大触控区。
- **发布前强制审核**：标题 / 昵称 / 简介先过客户端黑名单过滤（政治敏感、公众人物敏感称呼、侮辱、低俗色情、违法违规五类，含全角/插符变体归一化），未通过无法发布并高亮命中类别。
- **分享传播**：Canvas 生成 900×1200 认证卡 PNG 下载，或一键复制带话题标签的传播文案。

## 技术栈

Vite + React 19 + TypeScript；原生 Canvas 2D 做像素化、分享卡与社区缩略图渲染；Web Audio API 现场合成全部音效（零音频文件）；手写 CSS 完成全部动效。零第三方运行时依赖（仅 react / react-dom）。
