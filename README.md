# 嬷嬷模拟器 momomoniqi

> 把你最严肃的角色，宠成全网嬷嬷。

纯前端的整活式**创意工作台** + DIY 同人二创社区：上传任意角色图或直接选一只**内置免版权原创角色**，10 秒像素化成"电子嬷嬷"，在**工作流导演台**里编一套动作脚本（摸头 / rua / 哄睡 / 丢球……）一键演出，攻向 / 嬷向语气随时切换，宠出离谱嬷力值；既可以一键生成竖版「嬷嬷认证卡」PNG 发社媒，也可以**过审后发布到社区展台**被点赞点彩，看中别人的作品还能一键「二创同款」。自带**电脑 / 手机设备预览台**与 **Electron 桌面预览包**。

产品规划详见 [docs/PRODUCT_PLAN.md](docs/PRODUCT_PLAN.md)。

## 本地运行

要求 Node.js ≥ 20。

```bash
npm install
npm run dev              # 开发服务器（默认 http://localhost:5173）
npm run build            # 类型检查 + 生产构建，产物在 dist/
npm run preview          # 预览生产构建

# 桌面预览版（Electron）
npm run preview:electron        # 构建并拉起桌面预览窗口
npm run build:preview           # Linux 目录包 → dist-preview/linux-unpacked/
npm run build:preview:appimage  # Linux AppImage 单文件
npm run build:preview:win       # Windows 免安装 exe（Linux 上可直接交叉编译）
```

网页产物纯静态，`dist/` 可直接部署到 GitHub Pages / 任意 CDN；桌面包产出说明详见 [releases/README.md](releases/README.md)。

## 功能概览

### 创意工作台（工坊）

- **导入角色**：拖拽 / 点击上传（全程浏览器本地处理，图片不出浏览器；最近 3 个角色可复用），或从**原创角色库**一键载入 —— 内置 6 只手绘像素角色（铁面姑姑 / 龙傲天总裁 / 赛博咪嬷 / 白切黑剑客 / 御膳房糖嬷 / 星际舰长），全部为本作原创，零版权顾虑；载入时有传送 spawn 动效 + 音效。
- **像素化 / 风格化**：颗粒度 16–96 格可调；7 种风格预设（像素原味 / 复古掌机 / 赛博粉 / 墨水印 / 拓麻液晶 / 贴纸手账 / 黑白漫画）。
- **工作流导演台**：四步步骤条（选角色 → 定风格 → 编脚本 → 出片）实时点亮当前进度；把 7 个互动动作**编排成最长 12 步的动作脚本**，「一键演出」按节拍自动连打制造冲击画面；内置 3 套爆款模板（宠溺连击 / 攻壳粉碎机 / 深夜哄睡直播）；工作流（角色 + 风格 + 语气 + 脚本）可**保存到本机、一键复演**，最多 6 套。
- **攻 / 嬷双语气包**：嬷向（威严破功）与攻向（低音炮高冷崩坏）两套完整文案池，覆盖全部动作与暴击语录；载入攻向角色自动切攻向语气；语气随认证卡话题标签与社区作品标签透传。
- **养育 + 数值**：精力 / 亲密度拓麻式养成、嬷力值 + 12% 暴击 + 五档成就、8-bit 合成音效（可静音）。

### 社区展台（本地模拟）

- 发布前**强制客户端审核**（五类黑名单 + 变体归一化），过审才可上架；免责声明固定可见。
- feed 卡片带风格 / 语气（攻向 / 嬷向）标签；点赞（可切换）、点彩（彩屑爆发）；8 条内置种子作品（含 3 条攻向二创）由原创角色 × 风格滤镜现场渲染。
- **二创同款**：任意作品一键把同款风格 + 语气 + 推荐脚本装进工坊，立刻开演自己的版本。

### 设备预览台 + 桌面预览包

- 导航「预览台」：应用装进**桌面显示器外框（1280×800）/ 手机外框（390×844）**里以真实视口内嵌预览，媒体查询真实生效，切换带 3D 入场动效；预览实例与主窗口共用本机数据，可直接上手玩。
- **Electron 桌面预览版**：`electron/` 主进程以自定义 `app://` 协议伺服前端产物（同源 iframe 可用），支持一键产出 Linux 目录包 / AppImage / **Windows 免安装 exe**（Linux 上可直接交叉编译，详见 [releases/README.md](releases/README.md)）。

### 分享传播

- Canvas 生成 900×1200 认证卡 PNG 下载，或一键复制带话题标签（#嬷向二创 / #攻向二创）的传播文案。

## 技术栈

Vite + React 19 + TypeScript；原生 Canvas 2D 做像素化、原创角色渲染、分享卡与社区缩略图；Web Audio API 现场合成全部音效（零音频文件）；手写 CSS 完成全部动效。**网页运行时零第三方依赖**（仅 react / react-dom）；electron / electron-builder 仅作为桌面预览包的开发期依赖。
