# 嬷嬷模拟器 momomoniqi

> 把你最严肃的角色，宠成全网嬷嬷。

纯前端的整活式互动玩具 + DIY 同人二创工作台：上传任意角色图（宫斗嬷嬷、老板头像、自家猫），自动流水线**抠背景 → 透明底立绘 → 像素化/风格化 → 入嬷登记建档**（本地启发式推断名号/人设标签/反差设定/声线），然后用摸头 / rua / 哄睡 / 丢球 / **嬷语开麦**等 8 个动作过度宠溺它（拓麻歌子式养育：精力 + 亲密度），还能**直接戳角色**触发分区反应、连击与长按彩蛋；贴纸装扮后进「出卡工作室」出 **3 种竖版嬷卡**（认证卡 / 反差对比卡 / 档案卡）发社媒，整套流程可存成「配方工作流」一键再跑，**过审后发布到社区展台**——作品帖被点赞点彩，玩法配方帖可被其他玩家一键套用。

产品规划详见 [docs/PRODUCT_PLAN.md](docs/PRODUCT_PLAN.md)。

## 本地运行

要求 Node.js ≥ 20。

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5173）
npm run build    # 类型检查 + 生产构建，产物在 dist/
npm run preview  # 预览生产构建
```

纯静态产物，`dist/` 可直接部署到 GitHub Pages / 任意 CDN。

## 功能概览

- **上传角色**：拖拽或点击选图，全程浏览器本地处理，图片不出浏览器；最近 3 个角色存 localStorage 可一键复用；未上传时使用内置像素嬷嬷。
- **幕后抠图（新）**：Canvas 启发式背景去除——边缘取样聚类背景色 + 四边泛洪 + 残点蚀刻 + 主体包围盒居中，输出透明底「角色立绘」；容差滑杆可调，背景太复杂自动回退原图；接真实 AI 分割的接口已预留。
- **入嬷登记 / 自动解析（新）**：上传即触发解析流水线动画（扫描线 + 五步清单 + 盖章音效），本地启发式推断角色档案——图像哈希做稳定种子，色彩统计出主色谱 / 高冷指数 / 活泼指数，文件名关键词推体质谱系（宫廷 / 职场 / 兽形 / 师门 / 玄学），生成名号、人设标签、反差设定、口头禅与档案声线；不满意可「换一卦」重推。
- **像素化 / 风格化**：颗粒度 16–96 格可调；**7 种风格预设** —— 像素原味、复古掌机（四色绿屏）、赛博粉（霓虹色阶）、墨水印（黑白盖章）、拓麻液晶（三阶灰绿电子宠物屏）、贴纸手账（粉彩糖果）、黑白漫画（1-bit 网点），基于亮度色阶映射 + Bayer 抖动实现。
- **互动开嬷**：摸摸头 / rua 一下 / 拍拍 / 喂食 / 哄睡 / 夸夸 / 丢球 / **嬷语开麦（新）**——按档案声线用 Web Audio 现场合成一串怪声嘟噜语（音高随机游走 + 白噪辅音 + 句尾语气），配「嬷语 + 官方翻译」字幕气泡；每个动作有专属角色形变动画、道具入场动画、粒子彩屑与 8-bit 音效（顶部导航一键静音，偏好持久化）。
- **直戳互动（新）**：直接点角色本体，顶戴 / 面门 / 衣摆三分区不同反应文案与怪声；900ms 内连戳出连击计数，5 / 10 / 20 连触发里程碑爆发；长按 550ms 触发「被捏住」彩蛋。
- **伪 3D 舞台（新）**：鼠标视差倾斜（CSS 3D transform + 景深分层），角色 / 粒子分层浮起，移动端自动关闭。
- **贴纸装扮（新）**：12 款贴纸点选上台、随机角度落位，点击可摘、可撤销清空，出卡时一并叠印。
- **养育状态**：精力 / 亲密度两条像素数值条，喂食哄睡回精力、玩耍涨亲密耗精力，实时派生心情文案——拓麻歌子式轻养成。
- **搞笑反馈**：每次互动随机弹出无厘头文案；嬷力值 +3~15，12% 概率触发暴击 +66（震屏 + 白闪 + 号角音效）；五档成就 toast。
- **出卡工作室（新）**：3 套 900×1200 竖版卡模板——**嬷嬷认证卡**（经典晒分）、**反差对比卡**（开嬷前威严存档 vs 开嬷后被宠化，去饱和旧照 + 撕裂分割带）、**嬷嬷档案卡**（名号 / 体质 / 标签 / 反差设定 / 口头禅 / 四维指数 / 主色谱 / 认证章）；预览支持 3D 倾斜与翻面（背面品牌纹），一键下载 PNG / 复制模板专属传播文案。
- **配方工作流（新）**：把「抠图 → 风格 → 贴纸 → 出卡模板」整套配置存成可复用配方（localStorage），一键再跑；还能把当前配方**发布成社区玩法帖**。
- **社区展台（本地模拟）**：作品帖 + **玩法配方帖（新）**双内容 feed（localStorage 持久化），支持点赞（可切换）与点彩（累加 + 彩色粒子爆发）；配方帖展示配方链路并支持**一键套用**（带回工坊重跑整条流水线）；内置 7 条种子内容，支持「全部 / 作品 / 玩法配方 / 我的」过滤；移动端单列 feed + 大触控区。
- **发布前强制审核**：标题 / 昵称 / 简介先过客户端黑名单过滤（政治敏感、公众人物敏感称呼、侮辱、低俗色情、违法违规五类，含全角/插符变体归一化），未通过无法发布并高亮命中类别。
- **分享传播**：Canvas 生成竖版卡 PNG 下载（适配小红书 / 抖音图文），或一键复制带话题标签的传播文案。

## 技术栈

Vite + React 19 + TypeScript；原生 Canvas 2D 做抠图（边缘泛洪）、像素化、三套分享卡与社区缩略图渲染；Web Audio API 现场合成全部音效与嬷语怪声（零音频文件）；手写 CSS 完成全部动效与伪 3D（perspective / preserve-3d）。零第三方运行时依赖（仅 react / react-dom）。
